# 指言 ZenTap

> 轻触输入，安静表达。

指言 ZenTap 是一款开源的 macOS 语音输入工具。它常驻为一个小小的悬浮窗：点击开始听写，再点击一次结束，并把识别出的文字输入到当前光标所在的位置。

## 初心

很多语音输入工具依赖键盘快捷键启动。对于不方便使用键盘的人来说，这一步本身就是门槛。

指言最初是为这些用户设计的，但它不只属于某一类人。它也适合任何希望少敲一点键盘、用更自然的方式写字、记录想法、回复消息的人。

我们希望它像桌面上的一片竹叶：轻轻一点，开始说话；再轻轻一点，文字落下。

## 特色

- **鼠标优先**：不需要键盘快捷键，点击悬浮窗即可开始或结束。
- **隐私优先**：使用 macOS 系统 Speech 框架，并要求本机离线识别。
- **不会上传**：项目没有网络上传逻辑，音频和文本都留在本机。
- **输入法桥接**：可把指言变成第三方输入法语音快捷键的鼠标开关，例如豆包输入法的 `fn` 语音快捷键。
- **中英支持**：右键菜单可切换中文和英文。
- **东方禅意设计**：青瓷湖面、竹叶、水波，保留标准模式和极简禅意模式。
- **开源共建**：欢迎无障碍、语言、本地化、设计、工程方向的贡献。

## 使用方法

1. 下载最新版 DMG：

   [ZenTap-0.1.1.dmg](https://github.com/Dovesoup/ZenTap/releases/latest/download/ZenTap-0.1.1.dmg)

2. 打开 DMG，把 `ZenTap.app` 拖到“应用程序”。
3. 首次打开时，macOS 可能提示“无法验证开发者”。这是因为当前开源包还没有做 Developer ID 公证；请右键点击 `ZenTap.app`，选择“打开”，再确认一次。
4. 第一次使用时，允许 macOS 请求的“麦克风”和“语音识别”权限。
5. 如果希望自动输入到当前文本框，请打开：

   ```text
   系统设置 -> 隐私与安全性 -> 辅助功能
   ```

   将 ZenTap 加入列表并打开权限。

6. 在任意文本框放好光标。
7. 点击 ZenTap 开始说话。
8. 再次点击 ZenTap，识别出的文字会输入到光标处。

## 豆包输入法桥接

如果你更喜欢豆包输入法的语音识别效果，可以让指言只负责“鼠标点击触发快捷键”。

右键指言悬浮窗，选择：

```text
输入引擎 -> 豆包快捷键
豆包快捷键 -> fn
```

豆包输入法当前默认推荐的语音快捷键是 `fn`。如果你在豆包里改成了其他快捷键，也可以在指言的“豆包快捷键”菜单里选择同样的组合。

这个模式下，第一次点击会触发豆包语音快捷键；第二次点击默认发送 `Shift`，用于停止豆包语音条，同时避免在聊天窗口里误触发发送。如果你的豆包版本行为不同，可以在“豆包结束方式”里改成 `Esc`、`Return` 或“重复启动快捷键”。其中 `Return` 会被部分聊天软件当作发送，请谨慎使用。

隐私提醒：指言内置的“系统离线识别”模式坚持本机识别；“豆包快捷键”模式下，语音识别由豆包输入法完成，会遵循豆包输入法自身的识别和隐私策略。

## 禅意模式

右键悬浮窗，勾选“禅意模式”后，界面会收成一个极简圆形：只保留青瓷湖面和竹叶。

这个模式适合长期放在屏幕边缘，不打扰，只在需要时轻轻唤醒。

## 隐私说明

ZenTap 的目标是离线、私密、透明。

- 使用 Apple Speech 框架。
- 启用 `requiresOnDeviceRecognition`。
- 如果当前语言没有本机识别资源，应用应拒绝开始识别，而不是偷偷联网。
- 项目代码中没有服务器、账号系统或上传路径。

## 当前限制

- 目前中文和英文需要手动切换。
- 离线识别资源由 macOS 管理，部分系统可能需要安装对应语言资源。
- 当前 DMG 使用本地临时签名，正式发布仍需要 Developer ID 签名和 notarization。
- 开发版每次重新构建后，macOS 辅助功能权限可能需要重新添加。

## 从源码构建

需要 macOS 和 Swift 命令行工具。

```bash
./build.sh
```

构建完成后，应用会出现在：

```text
~/Desktop/ZenTap.app
```

如需生成可发布的 DMG：

```bash
./scripts/build-dmg.sh
```

DMG 会生成在：

```text
dist/ZenTap-0.1.1.dmg
```
